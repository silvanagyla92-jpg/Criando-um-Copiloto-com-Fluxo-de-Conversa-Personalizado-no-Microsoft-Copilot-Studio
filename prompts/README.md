# Prompts utilizados na documentação

## Objetivo

Registrar os prompts utilizados para apoiar a análise, organização e revisão da documentação deste projeto.

## Prompt 01 — Análise documental

```text
Analise a estrutura deste projeto e identifique quais informações
são necessárias para produzir uma documentação técnica clara,
organizada e verificável. Diferencie informações confirmadas,
interpretações e informações que precisam de evidência.
```

## Prompt 02 — Estrutura da documentação

```text
Proponha uma estrutura de documentação técnica para um projeto
feito no Microsoft Copilot Studio, incluindo objetivo, metodologia,
arquitetura, fluxo conversacional, configuração, evidências,
resultados e referências oficiais.
```

## Prompt 03 — Revisão crítica

```text
Revise esta documentação e identifique afirmações que não podem
ser confirmadas pelo projeto ou por documentação oficial. Não
invente informações. Para cada lacuna, indique qual evidência
seria necessária.
```

## Prompt 04 — Validação de fontes

```text
Para cada afirmação técnica sobre Microsoft Copilot Studio,
priorize documentação oficial da Microsoft Learn. Diferencie
fatos documentados de inferências e não apresente como fato uma
configuração específica que não esteja comprovada.
```

## Observação

Os prompts acima documentam o processo de apoio por IA. Eles não substituem a validação humana nem a documentação oficial do produto.
