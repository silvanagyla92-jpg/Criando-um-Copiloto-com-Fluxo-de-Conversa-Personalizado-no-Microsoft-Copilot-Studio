# Diagramas

Esta pasta reúne os diagramas utilizados para explicar a solução.

## Diagramas planejados

### 1. Arquitetura conceitual

Representa a relação entre usuário, agente, tópicos, fluxo conversacional e fallback.

### 2. Fluxo conversacional

Representa a sequência de entrada, reconhecimento, processamento e resposta.

## Regra

Os diagramas devem diferenciar arquitetura conceitual de configuração comprovada. Um diagrama explicativo não deve ser apresentado como uma captura da configuração real do Copilot Studio.

## Referência

A estrutura conceitual deve ser compatível com a documentação oficial do Microsoft Copilot Studio sobre tópicos, gatilhos e Fallback:

- https://learn.microsoft.com/pt-br/microsoft-copilot-studio/authoring-create-edit-topics
- https://learn.microsoft.com/en-us/microsoft-copilot-studio/guidance/triggering-topics
- https://learn.microsoft.com/pt-br/microsoft-copilot-studio/authoring-system-fallback-topic
