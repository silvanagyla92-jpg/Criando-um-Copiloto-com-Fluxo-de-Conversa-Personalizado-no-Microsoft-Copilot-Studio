# Criando um Copiloto com Fluxo de Conversa Personalizado no Microsoft Copilot Studio

## Sobre o desafio
Este repositório documenta o desafio de criar um Copilot com fluxo de conversa
personalizado no Microsoft Copilot Studio, como parte do bootcamp **Microsoft AI
for Tech - Copilot Studio** da DIO (Digital Innovation One).

## Sobre o Microsoft Copilot Studio
O Microsoft Copilot Studio é uma plataforma **low-code/no-code** que permite
criar assistentes de conversação (copilots) inteligentes sem exigir
conhecimento avançado de programação, eliminando a dependência de
desenvolvedores ou cientistas de dados para construir soluções de IA
conversacional.

## O que foi aprendido

### 1. Criar um Copilot em branco
Como iniciar um agente conversacional do zero no Microsoft Copilot Studio,
partindo de um modelo vazio para construir a lógica de conversa manualmente,
sem depender de templates prontos.

### 2. Customizar um tópico
Como estruturar um "tópico" (unidade de conversa) dentro do Copilot Studio,
definindo frases-gatilho (trigger phrases) que ativam aquele fluxo específico
e o caminho de perguntas e respostas correspondente.

### 3. Personalizar uma mensagem de erro de tópico
Como configurar mensagens de fallback/erro personalizadas, exibidas quando o
Copilot não entende a entrada do usuário ou quando o fluxo não encontra uma
resposta esperada — melhorando a experiência do usuário em cenários de falha.

### 4. Aumentar e diminuir a qualidade da resposta com GenAI
Como ajustar os parâmetros de geração de respostas baseadas em IA generativa
dentro do Copilot Studio, controlando o equilíbrio entre respostas mais
criativas/abertas e respostas mais precisas/controladas.

## Resultado
Ao final do desafio, foi construído um Copilot funcional, com fluxo de
conversa customizado, mensagens de erro tratadas e respostas otimizadas via
GenAI para interações mais precisas e eficientes.

## Tecnologias utilizadas
- Microsoft Copilot Studio
- IA Generativa (GenAI)
