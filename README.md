# Criando um Copiloto com Fluxo de Conversa Personalizado no Microsoft Copilot Studio

## 1. Sobre o desafio

Este repositório documenta o desafio de criar um Copilot com fluxo de conversa personalizado no Microsoft Copilot Studio, como parte do bootcamp **Microsoft AI for Tech - Copilot Studio** da DIO (Digital Innovation One).

## 2. Sobre o Microsoft Copilot Studio

O Microsoft Copilot Studio é uma plataforma para criação de agentes e experiências conversacionais com recursos de IA. A plataforma oferece recursos de criação e configuração de tópicos, gatilhos, nós de conversa, respostas generativas e outras capacidades de IA. Consulte a [documentação oficial do Microsoft Copilot Studio](https://learn.microsoft.com/pt-br/microsoft-copilot-studio/) para informações atualizadas.

> **Nota de precisão:** as informações específicas sobre o que foi realizado neste projeto são baseadas no registro original do desafio. Configurações específicas do ambiente devem ser confirmadas pelas evidências reais do projeto.

## 3. O que foi aprendido

### 3.1 Criar um Copilot em branco

Como iniciar um agente conversacional do zero no Microsoft Copilot Studio, partindo de um modelo vazio para construir a lógica de conversa manualmente, sem depender de templates prontos.

### 3.2 Customizar um tópico

Como estruturar um tópico dentro do Copilot Studio, definindo o fluxo de conversa e os mecanismos utilizados para iniciar e conduzir uma interação. A documentação oficial apresenta os tópicos como elementos centrais para definir como um agente responde a determinadas interações.

### 3.3 Personalizar uma mensagem de erro de tópico

Como configurar mensagens de fallback/erro para cenários nos quais o agente não consegue compreender adequadamente a entrada do usuário ou não consegue direcionar a interação para um tópico apropriado.

### 3.4 Ajustar respostas com recursos de IA generativa

Como explorar recursos de IA generativa disponíveis no Copilot Studio para produzir ou aprimorar respostas. A configuração e o comportamento efetivamente utilizados neste projeto devem ser confirmados pelas evidências da execução original.

## 4. Resultado

Ao final do desafio, foi registrado no projeto um Copilot com fluxo de conversa customizado, tratamento de mensagens de erro e utilização de recursos de IA generativa. As evidências visuais serão utilizadas para comprovar as configurações e os resultados efetivamente obtidos.

## 5. Tecnologias utilizadas

- Microsoft Copilot Studio
- Inteligência Artificial Generativa (GenAI)
- Microsoft Learn — documentação técnica oficial
