# 01 — Metodologia

## Objetivo

Documentar de forma reproduzível um projeto de agente conversacional criado no Microsoft Copilot Studio, distinguindo fatos observados no projeto de informações gerais obtidas na documentação oficial.

## Etapas

1. Identificar o objetivo do desafio original.
2. Descrever os componentes do agente e do tópico.
3. Registrar como o fluxo conversacional é organizado.
4. Explicar conceitos do Copilot Studio usando Microsoft Learn como fonte primária.
5. Inserir evidências visuais reais do ambiente utilizado.
6. Revisar a documentação para evitar afirmações não comprovadas.

## Uso de IA na documentação

A IA pode apoiar a organização, revisão e expansão da documentação. O resultado deve ser validado contra o projeto real e contra fontes oficiais. A IA não deve ser tratada como fonte primária para fatos sobre o produto quando a documentação oficial estiver disponível.

## Critério de confiabilidade

- **Fato do projeto:** confirmado pelo conteúdo do repositório ou por evidência visual.
- **Fato técnico:** confirmado prioritariamente pelo Microsoft Learn.
- **Interpretação:** apresentada como interpretação.
- **Informação não confirmada:** não é apresentada como fato.
